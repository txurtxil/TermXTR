# TermXTR

Terminal SSH/SFTP para Android (Flutter). v2.0.0.

## Funciones
- Gestion de hosts SSH (password o clave PEM), credenciales cifradas en el dispositivo
- Terminal SSH interactiva multi-sesion (xterm), known_hosts con verificacion de huella
- Explorador SFTP: navegacion, subidas/descargas, favoritos, pool de conexiones
- Editor de texto integrado: busqueda, ajuste de linea, undo/redo, guardar en remoto
- Grabadora de sesiones, vault de portapapeles, keybar configurable
